# RDM Template Hub 
DOI

## Overview
This repository contains a collection collection of reusable Research Data Management (RDM) templates to use in your project. These inlclude metadata templates for repositories such as Zenodo and PHAIDRA,  as well as READMEs that you can copy and adapt for your projects.

## Where to get started 
- `templates/READMEs` — collection of READMEs, both in English and German, that can be used within code repositories, to accompany datasets or entire projects
- `templates/metadata` — WIP
