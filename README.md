# RDM Template Hub 

## Overview
This repository contains a collection collection of reusable Research Data Management (RDM) templates to use in your project. These include metadata templates for repositories such as Zenodo and PHAIDRA,  as well as READMEs that you can copy and adapt for your projects.

## Get started 
- `templates/READMEs` — collection of READMEs, which can be used to accompany and describe code, datasets or entire projects.
- `templates/metadata` — WIP
